# DigiTools UI

A polished landing page and product experience for a digital tools platform built with modern React, Tailwind CSS, and DaisyUI.

## About the Project

DigiTools UI is a clean and responsive user interface that showcases premium digital products with pricing, product selection, and cart interaction. The project is designed to look professional while remaining simple to customize and extend.

## Technologies Used

- React
- Vite
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify

## Key Features

1. **Product Selection and Cart Flow**
   - Users can choose products, add them to the cart, and view selected items in a summary panel.
2. **Pricing and Promo Section**
   - Includes a responsive pricing section with highlighted plans and a strong CTA.
3. **Toast Notifications**
   - Displays feedback messages when products are added to the cart using React Toastify.
